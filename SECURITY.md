# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older Play releases may not receive fixes; update to the newest version offered on Google Play.

## Reporting a vulnerability

Please report security issues privately through the repository's **Security** tab using **Report a vulnerability**. Do not open a public issue for an exploitable bug. If private reporting is unavailable, contact the repository owner through their GitHub profile and do not include secrets, signing keys, tester addresses, or personal data in a public issue.

Include the affected app version, watch model and Wear OS version, steps to reproduce, and the likely impact. A maintainer will acknowledge the report and coordinate a fix and disclosure timeline with the reporter.
